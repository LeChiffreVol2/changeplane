# Open Source roadmap

The first public release is a free Apache-2.0 assessment tool, not an activation of the controlled hosted service. We prioritize installation success and useful decisions over feature count. Dates and targets below are experiments, not promises.

## First four weeks after release

- Five external repository installations across personal and organization accounts.
- Three installations still using assessments after four weeks.
- Document time to first useful assessment and every setup failure; aim for under ten minutes after selecting an existing behavioral job.
- Three user-confirmed useful findings, with a record of disputed findings and false blocks.
- Ask users which operational work they would pay us to own. No automatic telemetry is collected; request redacted, voluntary feedback.

## Candidates, ordered by evidence

1. Fix installation and evidence-identity problems observed in real repositories.
2. Add tested language/policy examples contributed by users with meaningful behavioral checks.
3. Expand collection bounds or event support only when real workloads need it and correctness is preserved.
4. Qualify hosted authority recovery and automatic reconciliation before any managed pilot.

Potential paid value includes managed installation/updates, reliable publisher operations and multi-repository administration. Pricing, service commitments and enterprise features require customer evidence and operating capacity. The open-source evaluator remains useful for individual and business users without a paid account.

Current infrastructure budget: USD 0. The separate USD 100 ceiling is a later scale decision. No managed model calls, new database projects, billing integrations or hosting upgrades are needed to publish Open Source. See [the operating budget](operating-budget.md).
