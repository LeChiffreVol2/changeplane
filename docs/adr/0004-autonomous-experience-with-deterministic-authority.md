# Make the experience autonomous while authority stays deterministic

ChangePlane will operate as an Autonomous Assurance Agent after three Deliberate Approvals: App installation and repository selection, protected setup-pull-request merge, and acceptance of the exact Ruleset plan. It may discover evidence, evaluate every new revision, publish Guard state, send a machine-readable handback, re-evaluate agent updates, reconcile stuck evaluations, and escalate protected or ambiguous work without another click. The deterministic harness alone decides the assurance result; Autonomous Repair remains a separately activated and separately credentialed expansion.

## Consequences

Product copy must not use “Autonomous” without distinguishing assurance automation from repair authority. The default product cannot write customer code, return PASS from a model, approve a pull request, or merge. Every blocked state names the safe consequence and one next action, while routine exact-head evaluation and recovery require no human interaction.
